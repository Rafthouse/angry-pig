ANGRY PIG - Dynamic Saturation 1.1.1 Beta 1 (Windows VST3)
EXPERIMENTAL BETA. Portable package, UNSIGNED. No installer, no registry changes.

Contents
  AngryPigDynamicSaturation.vst3   VST3 bundle, the verified build
                                   plugin name "Angry Pig Dynamic Saturation (candidate)", VST3 class ID APd2
                                   Gain range -36 to +36 dB (Angry Pig 1.0.0: -24 to +18 dB)
  THIRD_PARTY_NOTICES.txt          third-party notices (copied from the Angry Pig 1.0.0 bundle)

Install by hand
  1. Close all DAWs and plugin hosts.
  2. Copy the folder AngryPigDynamicSaturation.vst3 to
         C:\Program Files\Common Files\VST3\
     Writing there needs administrator rights. Your host must scan this folder.
  3. Rescan plugins in the host.

Uninstall by hand
  Delete the folder C:\Program Files\Common Files\VST3\AngryPigDynamicSaturation.vst3
  Angry Pig 1.0.0 (AngryPigSpike.vst3) is a different bundle; leave it alone.

Alternative: the Setup .exe does the same copy with integrity checks, a log and a clean uninstall.
Use one or the other, not both.

Requirements
  Windows 10/11 x64. Microsoft Edge WebView2 Runtime (the GUI needs it; this package does not install it).
  If Windows marked the ZIP as downloaded: right-click it, Properties, Unblock, then extract.

Notes
  Not code-signed. SmartScreen and the host may warn about the publisher.
  Dynamic Saturation is experimental. Report sound, GUI and host problems with your DAW name and version, and your Windows version.
